# 🍓 FruitLens AI

FruitLens AI is an AI-powered web application that recognizes fruits from images and provides useful information about them.

## ✨ Features

- 📷 Fruit image recognition
- 🤖 AI prediction
- 📊 Prediction confidence
- 🔎 AI Second Opinion
- 🍎 Fruit information
- 💡 Fruit benefits and fun facts
- 🍽️ Fruit Match recommendations
- 🕒 Scan history

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- TensorFlow.js
- Teachable Machine

## 🎯 Purpose

FruitLens AI is designed to make fruit recognition and learning about fruits easier and more interactive through AI.
